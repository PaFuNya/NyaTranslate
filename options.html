关于

NyaTranslate-喵译 的版本信息与使用说明。

NyaTranslate-喵译
基于 Manifest V3 的 Chrome 扩展，接入 DeepSeek 与通义千问，
让 AI 驱动的翻译与术语解释触手可及。
使用说明
  1. 在API 配置页添加模型，并填写各服务商的 Key 与端点。
  2. 在触发规则页配置各场景的触发方式（默认：划词显示小图标）。
  3. 在任意网页上，用鼠标划选文字（1~500 字符）。
  4. 点击出现的气泡图标，已启用的模型将同时返回结果。
  5. 点击面板顶部的固定按钮可钉住面板，方便连续查词。
隐私声明 所有 API Key 仅通过chrome.storage.local保存在本机， 不会传输至任何第三方服务器。每次查询的文本直接发往你配置的 API 端点。
